How it works

Your secret is encrypted in this browser before anything is sent. The key stays in the part of the link after the #, which browsers never send to a server, so the server only ever holds scrambled data it cannot read. Once the link has been opened as many times as the sender allowed (once, unless they chose more), that data is deleted.
